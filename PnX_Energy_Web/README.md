# PnX_Energy_Web

本项目现在以**网页控制台**为主：浏览器通过 BLE 连接 HC-42D，HC-42D 再以 UART 连接 RoboMaster C 板，C 板经 CAN 控制 5 块从板。旧版微信小程序源码仅作为备份保留。

**目前优先使用网页版：** 电脑 Chrome/Edge 或安卓 Chrome 打开 `web/`。先看 [今天使用步骤](docs/07-网页版今天使用.md)。连接主板并收到确认后，可选择小符或大符测试。

网页切换到其他标签或应用时不再主动断开；返回后会继续同步主板状态。浏览器或系统仍可能在后台暂停蓝牙与定时器，主板超过 6 秒收不到心跳会安全停止测试；此时返回网页会回到首页。关闭或离开网页时仍尝试停止并断开，不能把后台保持连接当作安全保证。

## 目录

- `miniprogram/`：此前开发的小程序备份；当前使用网页不需要打开它。
- `web/`：不需要小程序账号的网页版本；`start-web.cmd` 可在本机启动。
- `docs/`：协议、主板实现、导入联调与验收说明。
- `tests/`：协议、状态机、ACK 与超时自动化测试。
- `tools/master_simulator.py`：配合 HC-T 测试架，在主板固件完成前模拟 C 板。

## 先体验网页版

1. 双击项目根目录的 `start-web.cmd`。
2. 在同一台电脑的 Chrome / Edge 输入 `http://localhost:8080`。
3. 点击“无硬件演示”，可以完整走通小符、大符、未击中、五击和闪烁流程。

“无硬件演示”有醒目标识，不会连接或控制真实硬件。真实连接必须收到主板 `HELLO` 回执后才解锁模式按钮。
