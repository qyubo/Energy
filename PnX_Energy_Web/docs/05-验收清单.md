## 需要你现场完成/确认

- [ ] 若未来启用备份的微信小程序，再考虑 AppID；当前网页版不需要。
- [ ] HC-42D AT 测试通过，确认实际设备名、FFE0/FFE1 和波特率。
- [ ] 选择 C 板 USART1 或 USART6，确认接口可物理接出且未冲突。
- [x] C 板代码已写入 USART1 协议、ACK、大小符游戏状态机和看门狗；实际联调尚未验收。当前 UART 是逐字节中断接收，不是 DMA。
- [ ] 压力事件接入、完整硬件联调。
- [ ] 五块新从板分别设置节点 1～5。
- [ ] 单从板 CAN 验证，再扩到五块板。
- [ ] 验证大小符每种灯效和 10 次闪烁节拍。
- [ ] 验证错误压力位置、手机 MISS、退出、断电与断线安全状态。
- [ ] 决定并实现外围灯条、电机和正式 2.5 秒规则。
- [ ] 若要求“手机成功=灯板真的执行”，补从板 CAN 回执与主板聚合确认。

## 最终通过标准

连续进行至少 30 轮大小符交替测试，无重复目标、无丢步、无一次点击执行两次；任意时刻断开手机后主板 6 秒内进入安全状态；所有错误都能在手机或调试日志中定位到 BLE、UART、主板状态机、CAN 或从板层级。
