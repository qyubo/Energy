## 尚不能在纯软件环境替你完成的部分

1. 注册微信小程序 AppID并在荣耀手机真机授权 BLE。
2. 用 HC-T 确认模块实际波特率与 UUID。
3. 后续 C 板已实现 USART1 协议和大小符状态机；仍需烧录实测。本网页任务未修改主从板。
4. 统一波特率：C 板 USART1 现为 115200；HC-42D 若仍为出厂 9600，需要改为 115200。
5. 单从板再五从板实物联调，确认 CAN 节点、终端和灯效。
6. 外围灯条、电机、正式2.5秒自动判负规则仍待需求确认和板端实现。

## 推荐执行顺序

先在微信开发者工具跑“无硬件演示” → HC-T + 模拟器验证 BLE/UART → C板只通 HELLO/STATUS → 接一块从板验证五种 CAN 命令 → 实现完整状态机 → 接齐五块板 → 最后加入压力传感器及外围设备。
