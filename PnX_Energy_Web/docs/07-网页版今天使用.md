# PnX Energy 网页版：今天怎么用

## 与小程序的关系

网页版在 `web/`；原有微信小程序仍保留在 `miniprogram/`，没有删除。两者共用协议和状态机。修改 `miniprogram/lib/` 或 `web/src/` 后运行 `npm run build:web`，生成供浏览器直接加载的 `web/app.js`。

## 当前主板已实现的范围

重新只读检查 `Energy_New/Master_energy_new`：

- `Core/Src/usart.c`：USART1 已是 **115200 8N1**，PA9 TX、PB7 RX。
- `User/Bluetooth/bluetooth.c`：USART1 上处理 `HELLO/STATUS/START/HIT/MISS/STOP`，ACK 为 JSON + LF；手机/网页协议匹配。
- `User/Energy/energy.c`：小符随机未完成目标，完成后全红一环闪烁 10 次；大符按双靶、单靶交替推进至五格及最后一击，完成后全红八环闪烁 10 次。
- `Core/Src/app_threadx.c`：游戏任务周期调用 `Energy_Task()` 和 `Bluetooth_Task()`。
- 蓝牙 START 接受 `SMALL` 和 `LARGE`；网页收到主板确认后开放两种模式。

主板代码仍有待实物验证：串口接线、波特率、CAN总线、从板节点以及灯效。网页的成功提示代表主板 ACK，不代表从板已经物理亮起。

## 今天在这台电脑打开

1. 把 HC‑42D 接到 C 板 USART1：模块 TXD → C 板 PB7/RX，模块 RXD ← C 板 PA9/TX，共地，电源按模块标称接。模块与 C 板须都设 **115200 8N1**；HC‑42D 出厂默认常为 9600，需要先断开蓝牙，用 HC‑T 测试架配置。
2. 双击项目根目录的 `start-web.cmd`，保持命令窗口打开。
3. 在**同一台电脑**的 Chrome 或 Edge 地址栏输入 `http://localhost:8080`。
4. 先点“无硬件演示”检查页面。再点击“连接蓝牙设备”，浏览器会弹出系统设备选择框；选择 HC‑42D。
5. 显示“主板已连接”后，选择“小符测试”或“大符测试”。每次“击中”/“未击中”都等待主板确认。大符双靶时网页“击中”模拟主板状态中的 `target` 靶。

`localhost` 是浏览器认可的安全本机环境，因此这里不需要 HTTPS；但**不能把 `localhost` 链接发给别人使用**。

## 今天让其他电脑/安卓手机使用

最省事的方式是上传项目根目录的 `PnX_Energy_Web_upload.zip`：包内只有 `index.html`、`styles.css`、`overrides.css` 和 `app.js`，没有主从板工程。Cloudflare Pages 免费方案支持直接拖拽 ZIP：登录 Cloudflare 后进入 **Workers & Pages → Create application → Get started → Drag and drop your files**，填项目名、上传 ZIP、点 **Deploy site**，即可得到 `https://项目名.pages.dev`。然后把这个 HTTPS 链接发给测试者。无需小程序注册和微信审核，也无需云数据库。网址最好用浏览器直接打开，别在微信内置浏览器里测试 BLE。

以后修改网页源码后，先运行 `npm run build:web`，再更新四文件 ZIP，并在同一个 Pages 项目上传一次新部署；网址不会因本地文件保存而自动更新。

- Windows：Chrome / Edge，电脑必须具有 BLE 蓝牙硬件或 USB BLE 适配器。
- 安卓：Chrome，允许浏览器使用蓝牙及附近设备权限。
- iPhone：普通 Safari/Chrome 不支持此 Web Bluetooth 方案，**不能承诺可用**。

如果尚无 HTTPS 托管账户，今天最稳妥的是先在现场 Windows 电脑上用本机网页控制；其他人在同一电脑操作。要给不同设备发链接，还差一次 HTTPS 部署。

## 安全提示

- 浏览器离开页面会尝试发送 `STOP`；断线后主板的 6 秒看门狗必须实际生效。不要把网页关闭当成一定已停止。
- 打开网页的人如果在蓝牙距离内、拥有 HC‑42D 连接权限，就可能控制设备。公开网址只是入口，不是访问控制；正式现场使用应管理蓝牙配对/物理权限，必要时在主板协议中加入授权机制。
- 操作真实灯板前先低功率、单从板测试，确认 CAN 命令和停止行为。
