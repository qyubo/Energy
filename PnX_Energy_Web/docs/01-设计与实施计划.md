# PnX_Energy 开发计划

2026-09-19。此文是最初小程序阶段的规划；交付目录后来更名为 `PnX_Energy_Web`。主从板及厂家目录只读。

## 目标与约定
手机BLE → HC-42D → UART → C板 → CAN → 五从板；主板权威，ACK状态快照驱动界面。
大小符均有手动击中/未击中，大符还支持固件压力事件；用目标版本防止重复。
小符随机未完成组，命中后全红+一环；大符采用“两靶必击、单靶可击可不击”的交替阶段，非靶板依次显示1～5格进度。大符两靶未击中、最后一靶未击中时重开。
小符第五击后全红+一环，大符最后一击后全红+八环；亮250ms/灭250ms为一次，十次后保持亮。
当前手动测试默认不启用历史2.5秒超时，未选中组全黑，外围灯条/电机暂不控制。
退出及重新测试均STOP确认后回首页，断线不能声称已停；主板需心跳看门狗。

## 已知现状
主板CAN节点1~5，ID=0x300+编号，回复=0x100+编号，DLC1。
命令0 OFF、1 TARGET_ARROW、2 SMALL_HIT、3 PROGRESS（第二字节为1～5）、4 小符FINISH、5 大符FINISH、6 FINAL_TARGET。
本段是最初规划时的代码快照；截至网页版复查，主板已经新增 USART1 蓝牙协议与小符任务，USART1 改为 115200 8N1。最新状态以 `07-网页版今天使用.md` 为准。
HC42服务FFE0、特征FFE1、广播FFF0；模块AT指令未连接时发送，不带换行。

## 实施路径
1. 核对手册与新板代码，定义协议及集成清单。
2. 实现原生小程序、BLE服务、分包解析、ACK命令控制、中文界面。
3. 实现可测试主板逻辑模型、显式演示模式、HC-T串口模拟器。
4. 自动测试正常流程、超时、重复、断线、分包、异常包、十次闪烁。
5. 编写导入/联调/验收文档及检查报告。

## 边界
不修改或烧录板端、不安装厂家EXE、不用厂商AppID。硬件效果和手机真机布局必须现场验收。
